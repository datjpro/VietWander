# VietWander Web

Frontend web theo hướng `React JS`.

## Cách chạy
- `npm run dev:web`
- `npm run build:web`
- `npm run start:web`

## Ghi chú kỹ thuật
- UI web dùng React component + hooks.
- Firebase dùng Web SDK trực tiếp.
- Build/dev hiện dùng static server để ổn định trên máy Windows đang gặp `spawn EPERM` với bundler native.
- Khi môi trường ổn định hơn có thể nâng tiếp lên Vite rất nhanh.
